## Clonar el proyecto

Para descargar el proyecto:

git clone https://github.com/AgustinYS/WALLETDIGITAL.git

Luego ingresar a la carpeta:

cd WALLETDIGITAL

## Ejecutar el proyecto

1. Instalar XAMPP.
2. Copiar la carpeta WALLETDIGITAL dentro de `htdocs`.
3. Iniciar Apache y MySQL desde XAMPP.
4. Crear la base de datos utilizando el archivo `database.sql`.
5. Configurar la conexión a la base de datos en `config.php`.
6. Abrir el proyecto desde localhost en el navegador.

## Funcionalidades

La aplicación permite gestionar información relacionada con los gastos personales mediante diferentes módulos.

Entre sus archivos principales se encuentran:

- `registro.php`: registro de usuarios.
- `login.php`: inicio de sesión.
- `dashboard.php`: panel principal.
- `movimientos.php`: gestión de movimientos.
- `presupuesto.php`: gestión del presupuesto.
- `logout.php`: cierre de sesión.

## Control de versiones

Durante el desarrollo del proyecto se utilizó Git para:

- Realizar commits de los cambios.

- Resolver conflictos.
- Utilizar Git Stash.
- Realizar Rebase interactivo.
- Crear Tags para identificar versiones.

## Contribuir al proyecto

Para trabajar en una nueva funcionalidad se recomienda crear una rama:

git switch -c nombre-rama

Después de realizar los cambios:

git add .
git commit -m "Descripción del cambio"

Finalmente, los cambios pueden ser enviados al repositorio remoto mediante Git Push.
